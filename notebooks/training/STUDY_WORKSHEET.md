# Worksheet for a DeepRootGen pilot

Copy this worksheet into the study notebook. Fill it in before asking Claude
to design the search or running the final field assessment.

| Decision | Record |
|---|---|
| Prediction goal | Root pattern to reproduce and the intended population or location |
| Data | Source, units, completeness, zero and missing conventions, unresolved checks |
| Observation rule | What the field method sees and how the simulator will reproduce that support |
| Development and evaluation splits | Grouping by whole tube, geographic block or whole vine, independent unit counts, and split date |
| Baseline | Schema-4 JSON, revision and fixed settings |
| Candidate variants | Exact law names and setting paths, affected orders, bounds and reasons |
| Manual exploration | Changes seen in Dash, graph and branching checks, and comparison with the baseline |
| Objective and feasibility | Score components and scales, mass definition and acceptable bounds, geometry requirements |
| Search design | Trial count per variant, seed panel, startup and resource limits, planned output directory |
| Frozen evaluation | Freeze date, saved JSON and hash, fixed law, fresh seeds, held positions and success criteria |
| Result | Trial counts, failures, best score, baseline and candidate results, uncertainty and limitations |

Print or save the resolved settings and the paths to the trial ledger
and replay files alongside the worksheet. Share only the cleared parts
when using the [Claude prompts](CLAUDE_PROMPTS.md).
