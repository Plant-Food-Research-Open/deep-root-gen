Root Grid Aggregation

Aggregate DeepRootGen root length and dry biomass within soil grid voxels.

The soil DataFrame must contain voxel boundary points with x and y horizontal and z vertical (negative downward). Root coordinates and lengths are in cm; root tissue density is in g/cm3.

deeprootgen.statistics.root_grid_aggregation.aggregate_root_grid(node_df: DataFrame, soil_df: DataFrame, length_source: str = 'recorded') → tuple[DataFrame, DataFrame][source]

Return (per-voxel metrics, per-plant in-grid biomass totals).

Root segments are the edges from a parent node to each non-base child node. Each segment’s length is clipped and split between the soil voxels it crosses. Dry mass for a segment is pi*(diameter/2)^2*length*RTD.

length_source=’recorded’ allocates each stored segment length in proportion to the geometric fraction inside each voxel. ‘geometric’ uses endpoint distances instead. All lengths and dimensions are assumed to be cm.

Returns:

Summary Statistics

Summary statistics for hierarchical DeepRootGen root-system architectures.

Input is the node DataFrame returned by simulation.G.as_df(). A root segment is the edge from a node’s parent to that node; its attributes belong to the child node. Only valid child segments of order > 0 are measured.

Lengths default to 3D geometric lengths. Pass length_source=’recorded’ to use the stored node length instead. In particular, voxel statistics include only the part of a segment lying inside the supplied soil grid.
